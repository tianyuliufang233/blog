kubernetes1.31踩坑记录

2024-10-12 发布在 领域, kubernetes

openEuler 22重启后，docker网络丢失，docker-compose up -d network not found

原因：由于docker daemon状态无法及时刷新到磁盘，导致重启后docker daemon状态不正常。
解决方式：在/etc/sysconfig/docker文件中加入DISABLE_CRASH_FILES_DELETE=true
参考：
系统掉电影响 openEuler network not found

openEuler 20.3升级到22.03

# 先备份源文件

k8s calico 报 “Unable to create token for CNI kubeconfig error=Post”

原因：kube-proxy 未正常启动
参考：Unable to create token for CNI kubeconfig error=Post
container install-cni (init) in calico pod Unable to create token for CNI kubeconfig error=Post dial tcp 10.233.0.1:443: i/o timeout

node无法加入集群，报已加入的节点不能修改为现有节点node name

原因：kubelet加入集群读取错误的hostname，生成的kubelet证书cn名hostname不一致
临时处理：kubelet.service 中加入–hostname-override直接指定node name

containerd 使用ctr拉取http的镜像源镜像

加入 –plain-http

使用kubectl连接kube-apiserver报错：“The connection to the server localhost:8080 was refused - did you specify the right host or port?”

原因：未执行kubectl config use-context kubernetes –kubeconfig=kube.config 解决方式： 执行kubectl config use-context kubernetes –kubeconfig=kube.config 参考：kubectl命令出现错误“The connection to the server localhost:8080 was refused

# 10.106.0.0/16为vpn网段，tunl0为pod网络，经过input后直接通过calico的tunl0转发了，所以eth0的MASQUERADE没有起作用。
